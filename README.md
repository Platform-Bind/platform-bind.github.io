This is the repository for the Platform Bind curated collection of open and public sources.

## No AI use in the writing of content
No AI is used for writing the content of this curation; the purpose is to create a human-curated collection of relevant links and sources.

## AI use in the construction of the code running the site
AI Coding agents are used to create the code that runs this site as well as its design. The initial structure was created using Claude Code. 

## Using github in a project on digital dependencies
Do we walk the talk when using MS-owned github for a project on digital dependencies? Yes, we think so. The digital is inherently interconnected, so handling dependencies is not about being disconnected, but knowing how to handle them.
